Portugues:

Big O Notation

TEMPORAL: O(LOG N) O input aumenta exponecialmente e o tempo de execução aumenta linearmente.

ESPACIAL: O (1)  complexidade espacial constante, pois a forma que foi criada a logica não descarta array, tendo que sempre recriar array. Com um ponteiro no inicio e final, então
sempre encontraremos a metade do array e nova metade sucessivamente, assim sendo menos custoso para a memoria.

English:

TEMPORAL: O(LOG N) The input increases exponentially and the execution time increases linearly.

SPACE: O (1) constant space complexity, because the way the logic was created doesn't discard arrays, so you always have to recreate arrays. With a pointer at the beginning and end, then
we will always find half of the array and a new half in succession, so it is less costly for the memory.
